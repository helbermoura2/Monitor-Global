# Brazilian municipality seats

`br-municipalities.json`: IBGE code, name, UF, longitude, latitude.
Vendored from https://github.com/kelvins/municipios-brasileiros (MIT license included).
Coordinates identify the municipal seat, not the warning boundary or a measured weather event.
Matches require an exact normalized name plus UF, or a unique name within the warning states.
Unmatched/ambiguous cities remain in the warning list without invented coordinates.
