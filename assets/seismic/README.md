# GlobalQuake / iasp91 travel times

Source: https://github.com/xspanger3770/GlobalQuake/tree/00d63afae10fcb910f7609873bf85c8d80566eaa

The original `GlobalQuakeCore/src/main/resources/travel_table/travel_table.dat`
was generated by TauP with the iasp91 Earth model. Its SHA256 is
`8c0e24ea24d746cf4a7c33212614b3228908b1760bae4375460a4ab3cd4dd762`.
The MIT license is reproduced in `GLOBALQUAKE-LICENSE.txt`.

`globalquake-iasp91.bin.gz` preserves the original Float32 values for all four
phase families, depths 0–750 km in 1 km steps, angular distances in 0.1° steps:
P and S (0–150°), PKP (140–180°), PKIKP/PKiKP (0–180°). It is 4.46 MB once,
cached and reused. No interpolation samples are dropped or rounded.

Rebuild with `tools/build-globalquake-table.py` and the original Java file.
The binary format is magic `GQTT0001`, little-endian uint32 JSON header length,
UTF-8 table metadata, then each table's Float32 bit patterns XORed with their
previous value in the same row and arranged in four byte planes, gzip-compressed.
SHA256: `667220118849e2c6edca6098943d442be25a6df7d2981aecfcdc4f6ffa2edd26`.

`js/globalquake-travel.js` ports GlobalQuake's bilinear interpolation, inverse
binary search (1e-4° tolerance), missing-arrival handling and distance conversion
(40,082 km circumference; geometry uses its 6,379 km Earth radius).
The radius is independent of magnitude. It does not predict local shaking or
confirm that a tremor was felt. Missing/out-of-range arrivals render no ring;
failed loading does not fall back to an invented constant speed.

`tests/fixtures/globalquake-travel-reference.json` was generated by running the
original Java `TauPTravelTimeCalculator` methods against the original serialized
file: 7 depths, 11 elapsed times, 4 phases (308 comparisons). The browser/Node
implementation must agree to less than 1e-10 degrees. The fixture includes
fractional depths, deep earthquakes, vertical travel delays, shadow zones and
expired fronts. Time-real scenes use the published UTC origin; manual replay
uses the same model at 1× speed with a separately labelled replay clock.

The presentation protects a live/manual selection until the P-front camera
finishes opening. It then holds the last model-calculated frame for five seconds,
labelled "Quadro final", before resuming normal rotation. Larger newly arrived
earthquakes can preempt that hold; equal/smaller arrivals wait. Manual selection
and map interaction remain available. The final frame is a labelled snapshot,
not a claim that the physical waves stopped.

## Estimated shaking on land (M5+)

`js/seismic-impact.js` uses the pinned GlobalQuake `GeoUtils.pgaFunction`
Gen2 and MMI thresholds/colors. The ground distance uses GlobalQuake's spherical chord between the
hypocenter and the surface point (Earth radius 6379 km).
There are no local soil corrections or observed intensity reports.
48 geodesic intensity bands are intersected with land; the S wave reveals
completed bands. The layer is explicitly labeled as estimated.

`ne-50m-land.geojson` is Natural Earth 1:50m land, public domain:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson
Coasts and small islands are limited by this scale.
Intersection uses vendored polygon-clipping 0.15.7 (MIT license included).
