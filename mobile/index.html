◉ MONITOR GLOBAL

Uma primeira versão para o seu celular

Android 9 ou superior · versão de teste 0.1.0

Início, mapa de eventos, tempo e detalhes em uma interface para toque. Os dados vêm dos serviços do Monitor Global; a instalação é independente do aplicativo da TV.

Baixar APK de teste para Android

Como instalar

  1. Baixe o arquivo APK pelo botão acima.
  2. Abra o arquivo em Downloads no celular.
  3. Se o Android solicitar, autorize a instalação pelo navegador e confirme.

O aplicativo aparece como Monitor Global · Teste.

O que você pode experimentar

  • Consultar eventos e suas fontes.
  • Explorar o mapa e abrir os detalhes.
  • Acompanhar o tempo e a chuva da Liberdade, em São Paulo.
  • Compartilhar informações de um evento.

Sobre os avisos

Nesta primeira versão, os dados atualizam enquanto o aplicativo está aberto. O envio de notificações com a tela apagada será uma próxima etapa. Para receber os avisos do canal oficial, acompanhe @monitor_global.

Dados salvos podem ser consultados quando uma atualização falha. Previsões vencidas e informações ausentes são identificadas. O mapa e as novas consultas precisam de conexão.

As informações dependem das fontes e não substituem os avisos das autoridades. Esta é uma versão inicial para testes, fora da Play Store.
